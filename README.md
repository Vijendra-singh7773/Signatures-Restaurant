# Signatures Restaurant Website

A responsive restaurant landing page built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in your browser, or use VS Code Live Server for local development.

## Included
- Responsive desktop and mobile layout with mobile navigation
- Hero, story, menu highlights, gallery, guest reviews and visit/contact sections
- WhatsApp reservation/message links and phone link
- Google Maps directions and review links
- Uploaded restaurant and food photos in `assets/`

## Customize
- Update text/menu highlights in `index.html`.
- Replace images in `assets/` (keep the same filenames or update the HTML/CSS paths).
- Update phone number and external links if needed.
- `style.css` contains all styling and responsive breakpoints.
